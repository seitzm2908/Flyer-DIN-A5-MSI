# Melia Trend-Monitoring — Immobilienmarkt & Content-Trends

## Was Melia wöchentlich beobachtet

### 1. Immobilienmarkt-Trends (Rheinhessen & Deutschland)

#### Quellen (wöchentlich):
```
MARKTDATEN:
□ ImmobilienScout24 Marktreport → immoscout24.de/immobilienpreise
□ Immowelt Preisatlas → immowelt.de/ratgeber/immobilienpreise
□ Empirica-Regio → empirica-regio.de (Worms, Rheinhessen)
□ Bundesbank Immobilienpreise → bundesbank.de

REGION SPEZIELL:
□ Rhein-Zeitung / Allgemeine Zeitung (Worms) → Immobilien-Berichte
□ Wirtschaftsförderung Worms → Stadtentwicklung, Baugebiete
□ Kreisverwaltung Alzey-Worms → Lokale Infos

BUNDESWEIT:
□ Postbank Wohnatlas
□ vdp-Transaktionsdatenbank
□ DIHK Konjunkturumfragen
```

#### Content aus Markttrends generieren:
```
WENN Preise steigen →
  Post: "Warum jetzt der richtige Moment zum Verkauf ist"
  
WENN Preise stagnieren →
  Post: "Stagnation ≠ schlechte Zeit. Was Strategie jetzt bedeutet"
  
WENN Zinsen steigen →
  Post: "Steigende Zinsen: Was das für Verkäufer in Worms bedeutet"
  
WENN Zinsen fallen →
  Post: "Käufer kommen zurück — sind Sie bereit?"
  
WENN lokale Entwicklungen →
  Post: Neues Baugebiet, Infrastruktur, Wohnungsmangel etc.
```

### 2. Social-Media-Trends (Content-Format)

#### Was gerade auf Instagram & Facebook funktioniert:

**Formate beobachten (wöchentlich):**
```
□ Welche Immobilien-Konten wachsen gerade stark?
□ Welche Reel-Formate laufen gut? (Talking-Head, Text-only, Lifestyle?)
□ Welche Carousel-Themen generieren viel Engagement?
□ Was machen Top-Makler (DE) anders als Mittelklasse-Makler?
```

**Zu beobachtende Accounts (Best-Practice, nicht Konkurrenz):**
```
DEUTSCHLANDWEIT (Top-Makler-Content):
→ Suchbegriff: "Immobilienmakler" auf Instagram, nach Reichweite
→ Fokus: Wer wächst gerade, was posten die?

INTERNATIONAL (Inspiration):
→ US-Immobilienmakler (@tomferry Community, etc.)
→ UK-Luxury-Immobilien
→ Schweizer Premium-Makler
→ Österreichische Makler (kulturell ähnlich)
```

### 4. Ads-Monitoring (Mitbewerber-Anzeigen)

#### Google Ads Transparency Center:
```
URL: ads.google.com/transparency/advertiser/
→ Nach lokalen Maklern suchen
→ Welche Keywords buchen sie?
→ Welche Botschaften verwenden sie?
→ Seit wann laufen die Anzeigen?

ERKENNTNISSE NUTZEN:
→ Schwache Botschaften der Konkurrenz = unsere Chance
→ Starke Botschaften = Differenzierung schärfen
→ Lücken in ihrer Keyword-Strategie = unsere Felder besetzen
```

#### Meta Ads Library:
```
URL: facebook.com/ads/library
→ Nach Immobilienmakler + Region filtern
→ Wer schaltet aktiv in Worms/Rheinhessen?
→ Welche Creatives verwenden sie?
→ Seit wann läuft die Anzeige (lang laufend = profitabel)?

EIGENE ADS-IDEEN ABLEITEN:
→ Wenn Mitbewerber "Wohnungswert" testet → wir testen "Strategie vs. Preis"
→ Wenn Mitbewerber Fotos zeigt → wir zeigen Zahlen + Fotos
```
