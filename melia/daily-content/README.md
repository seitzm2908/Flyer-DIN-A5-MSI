# Melia Daily Content

Hier landen täglich automatisch 5 neue Hooks + Captions.

## Dateistruktur

```
YYYY-MM-DD.md   ← Tages-Datei (menschenlesbar)
latest.json     ← Aktuellster Tag (für Dashboard)
```

## Zugriff

- **GitHub:** Direkt in diesem Ordner die aktuelle Datei öffnen
- **Dashboard:** melia/dashboard/dashboard.html — zeigt latest.json an
- **E-Mail:** GitHub sendet automatisch eine Benachrichtigung bei neuem Commit

## Setup

Siehe MELIA.md → Abschnitt "Automatisierung einrichten"
